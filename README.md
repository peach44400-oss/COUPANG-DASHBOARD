# 쿠팡 통합 대시보드 (웹앱)

쿠팡 판매·물류 CSV를 업로드하면 브라우저에서 바로 분석하는 로컬 웹앱입니다.
로그인 없음 · 순수 데이터 분석용 · 모든 처리 온-디바이스(외부 전송 없음).

> `C:\Projects\suzy_data\dashboard_app.py`(tkinter) 를 **FastAPI 웹앱**으로 전환한 버전.
> 검증된 재무 공식(PPP/PMC/PPM·부가세 불변성)과 발주예측 3법은 그대로 이관했습니다.

## 실행
- 개발/소스: `실행.bat` 더블클릭 (또는 `python app/main.py`) → http://127.0.0.1:8700 자동 열림
- 배포: `게시.bat` 로 만든 `쿠팡대시보드.exe` 더블클릭 → 로컬 서버 실행 + 브라우저 자동 오픈

## 화면
- **통합 대시보드**: KPI · 추이 · 상품별 마진 · 실적확인 · 상품별 일자별 마진(PPM) · 물류/재고 · 센터별 성장 · 품절 · 품목×센터 / 상품×일자 매트릭스. 상단: 콘솔형 날짜 UI(범위 캘린더 + 월별/분기별) · 부가세(%·적용/제외) · 판촉비(PMC) 토글.
- **발주 예측**: 「거래처별·품목별 주문현황」 엑셀 업로드 → 3법(영업일평균·요일별평균·최근가중).
- **데이터 관리**: 파일 업로드(미리보기/적용) · 통합본 현황 · 엑셀 내보내기 · 마감 보관.
- **업데이트**: GitHub Releases 자동 업데이트 확인/설치(배포 exe 전용).

## 핵심 계산식 (검증됨 — 임의 변경 금지)
- GMV=매출액(부가세 포함), COGS=매입원가(부가세 제외)
- PPP = GMV/(1+부가세) − COGS · PMC = −쿠팡추가할인가/(1+부가세)
- PPM = (PPP [+PMC]) / GMV · **부가세 적용/제외를 바꿔도 PPM 불변**
- 실적확인은 PMC 무조건 반영, 상단 KPI·상품별마진은 PMC 토글로 on/off · 목표 기본 28%

## 새 버전 배포 (자동 업데이트)
1. `app/main.py` 의 `APP_VERSION` 올리기
2. `version.json` 의 `version`·`notes` 맞추기
3. `게시.bat` 더블클릭 (PyInstaller 빌드 → `gh release create`)
- 릴리스 저장소는 **Public** 이어야 무인증 다운로드가 됩니다.
- exe 옆 `update_url.txt` 로 재빌드 없이 배포 주소 변경 가능.
